# StaticMCP Implementation Guide for GitHub Pages Chatbot ## What is StaticMCP? StaticMCP is an approach to serving AI model context that combines the power of the Model Context Protocol (MCP) with the simplicity and performance of static file hosting. Instead of running complex server applications, StaticMCP pre-generates all responses as static JSON files that can be served from any CDN or static hosting provider. ## Key Benefits for GitHub Pages - **Zero Server Costs**: Perfect for GitHub Pages' static hosting - **No API Keys Required**: Content is pre-generated, not dynamically fetched - **Fast Performance**: Instant responses from static files - **Easy Deployment**: Just commit JSON files to your repo ## File Structure Create this structure in your GitHub Pages repository: ``` your-repo/ ├── index.html # Your chatbot interface ├── staticmcp/ # StaticMCP content directory │ ├── mcp.json # Main manifest file │ ├── resources/ # Pre-built resource responses │ │ ├── about.json │ │ ├── projects.json │ │ └── docs.json │ └── tools/ # Pre-built tool responses │ └── search/ │ ├── general.json │ └── tech.json └── js/ └── chatbot.js # Your chatbot logic ``` ## Step 1: Create the MCP Manifest Create `staticmcp/mcp.json`: ```json { "capabilities": { "resources": { "subscribe": false, "listChanged": false }, "tools": { "listChanged": false } }, "protocolVersion": "2024-11-05", "info": { "name": "My GitHub Pages Bot", "version": "1.0.0" }, "resources": [ { "uri": "resource://about", "name": "About Me", "description": "Personal information and background" }, { "uri": "resource://projects", "name": "My Projects", "description": "Portfolio of projects and work" } ], "tools": [ { "name": "search", "description": "Search through available content", "inputSchema": { "type": "object", "properties": { "query": { "type": "string", "description": "Search query" } }, "required": ["query"] } } ] } ``` ## Step 2: Create Resource Files Create `staticmcp/resources/about.json`: ```json { "contents": [ { "type": "text", "text": "I'm a developer passionate about AI and web technologies. I work with JavaScript, Python, and modern web frameworks. This chatbot can help you learn about my projects and experience." } ] } ``` Create `staticmcp/resources/projects.json`: ```json { "contents": [ { "type": "text", "text": "Here are some of my key projects:\n\n1. **Web Portfolio** - A responsive portfolio site built with HTML/CSS/JS\n2. **AI Chatbot** - This StaticMCP-powered chatbot you're using\n3. **Data Visualization** - Interactive charts using D3.js\n\nEach project demonstrates different aspects of modern web development." } ] } ``` ## Step 3: Create Tool Response Files Create `staticmcp/tools/search/general.json`: ```json { "content": [ { "type": "text", "text": "I found several topics I can help with:\n\n- **About**: Learn about my background and skills\n- **Projects**: Explore my portfolio and work\n- **Contact**: Ways to get in touch\n- **Technologies**: Programming languages and tools I use\n\nWhat would you like to know more about?" } ] } ``` ## Step 4: JavaScript Client Implementation Create `js/chatbot.js`: ```javascript class StaticMCPClient { constructor(baseUrl = './staticmcp') { this.baseUrl = baseUrl; this.manifest = null; } async init() { try { const response = await fetch(`${this.baseUrl}/mcp.json`); this.manifest = await response.json(); return true; } catch (error) { console.error('Failed to load MCP manifest:', error); return false; } } async getResource(uri) { try { // Convert resource URI to file path const resourceName = uri.replace('resource://', ''); const response = await fetch(`${this.baseUrl}/resources/${resourceName}.json`); const data = await response.json(); return data.contents[0].text; } catch (error) { console.error('Failed to load resource:', error); return 'Sorry, I couldn\'t find that information.'; } } async callTool(name, args) { try { if (name === 'search') { // Simple search implementation const query = args.query.toLowerCase(); let searchType = 'general'; if (query.includes('project')) searchType = 'projects'; if (query.includes('about') || query.includes('me')) searchType = 'about'; const response = await fetch(`${this.baseUrl}/tools/search/${searchType}.json`); const data = await response.json(); return data.content[0].text; } } catch (error) { console.error('Tool call failed:', error); return 'Sorry, I encountered an error processing your request.'; } } listResources() { return this.manifest?.resources || []; } listTools() { return this.manifest?.tools || []; } } // Chatbot Implementation class GitHubPagesChatbot { constructor() { this.mcpClient = new StaticMCPClient(); this.chatContainer = null; this.inputField = null; } async init() { await this.mcpClient.init(); this.setupUI(); this.addMessage('Hello! I\'m your personal AI assistant. Ask me about projects, background, or search for information.', 'bot'); } setupUI() { // Create chat interface (you'll need to add this to your HTML) this.chatContainer = document.getElementById('chat-messages'); this.inputField = document.getElementById('chat-input'); document.getElementById('send-button').addEventListener('click', () => { this.handleUserInput(); }); this.inputField.addEventListener('keypress', (e) => { if (e.key === 'Enter') { this.handleUserInput(); } }); } async handleUserInput() { const userInput = this.inputField.value.trim(); if (!userInput) return; this.addMessage(userInput, 'user'); this.inputField.value = ''; // Simple intent detection const lowerInput = userInput.toLowerCase(); let response = ''; if (lowerInput.includes('about') || lowerInput.includes('who are you')) { response = await this.mcpClient.getResource('resource://about'); } else if (lowerInput.includes('project')) { response = await this.mcpClient.getResource('resource://projects'); } else { response = await this.mcpClient.callTool('search', { query: userInput }); } this.addMessage(response, 'bot'); } addMessage(text, sender) { const messageDiv = document.createElement('div'); messageDiv.className = `message ${sender}`; messageDiv.textContent = text; this.chatContainer.appendChild(messageDiv); this.chatContainer.scrollTop = this.chatContainer.scrollHeight; } } // Initialize when page loads document.addEventListener('DOMContentLoaded', async () => { const chatbot = new GitHubPagesChatbot(); await chatbot.init(); }); ``` ## Step 5: HTML Interface Add to your `index.html`: ```html My AI Assistant
